# ToDo List

A Vue 3 app for tracking shopping items by importance. Items can be marked done, sorted by importance, and viewed on the dedicated Important page.

## Run locally

```sh
bun install
bun run dev
```

Build for production with `bun run build`.

## Pages

- **ToDo** — add items and view all, done, and unfinished items.
- **Modals** — examples of the modal components.
- **Important** — view only high importance items.
